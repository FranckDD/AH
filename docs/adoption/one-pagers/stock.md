## Every day

1. Sign in. Check that the indicator reads **Connected**. These screens have no offline mode.
2. **To check**: open each receipt and compare it with the goods and the delivery note. Check the lot number and the expiry date.
3. Figures right? **Validate**, then confirm. Figures wrong? Correct the quantities, or **Reject** with a reason.
4. Check each damage report.
5. Laboratory deliveries: read the requests and enter what arrived.
6. When a count is due, count the shelves: type each quantity, add a note for any gap, then **Validate the count**. The count is blind.
7. Assistant: mark manufactured lots as delivered, create receipts, declare damages. Print barcode labels with **Print labels**.

## Good to know

- Every product has an 8-digit code and a barcode label. The cash desk scans it.
- A gap found at the count becomes one correction request. The administrator decides. Do not change the stock yourself.
- Never conclude from an empty queue that nothing waits. Reload after a network cut.

> **If something goes wrong.** "Operation failed" or "Unable to load data": the network. Keep the numbers on screen, wait for the green indicator and press the button again. Do not refresh the page before that. Before you enter something again, check the list so it is not recorded twice. Note quantities on paper until the network returns.
